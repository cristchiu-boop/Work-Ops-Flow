# /ops-review 评审

先识别材料类型、阶段和目的，再逐项引用原文证据。阶段不适用项记N/A，缺失的必需项记0分。

维度：Goal目标口径；Fact事实追溯；Diagnosis证据与替代解释；Strategy机制与取舍；Action责任期限；Measurement反事实与护栏；Learning经验和边界。

每项0–10分：0缺失，1–3仅有断言，4–6基本成形但关键证据或执行条件不足，7–8闭环且主要缺口已解释，9–10证据扎实并明确边界。评分属于材料完整性判断，不代表业务成功概率。

输出：一句话判断；维度｜分数/N/A｜原文证据｜缺口｜修改建议；最优先修复的三处逻辑断点；可直接替换的段落（必要时）；待补数据。总体分为适用项算术平均，同时报告适用项数。不用平均分掩盖未验证根因、虚构事实和错误归因。
